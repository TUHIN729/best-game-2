Lumen Breaker is a Breakout-style arcade game: shatter every prism across 5 hand-designed levels with paddle, ball, power-ups and chain bonuses — 3 lives, a score chase, and a persistent best score.

## Run it

```sh
cd game && python3 -m http.server 8000
```

Then open http://localhost:8000 in a desktop browser and play.
